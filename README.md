# Cucumber
きゅうりの国

Web小説の原稿・設定・プロットを管理するリポジトリです（非公開）。
Claude Code が第一稿を書き、あなたが推敲して完成原稿にします。

---

## フォルダの見かた

```
works/                 作品
  README.md            作品一覧
  main/                本編
    README.md          作品カード（視点・文体など）
    plots/             プロット      ep001_plot.md
    drafts/            第一稿        ep001_draft.md   ← Claudeが書く
    final/             完成原稿      ep001_final.md   ← あなたが置く
    settings/          本編だけの設定
  spinoffs/            スピンオフ（作品ごとにフォルダを作る）
settings/              全作品共通の設定（キャラ・世界観・用語など）
templates/             テンプレート
docs/workflow.md       Claude向けの詳しい作業手順
CLAUDE.md              Claudeが必ず守るルール
```

- 話数は `ep001`, `ep002` … と3桁で書きます（並び順が崩れません）。
- 第一稿と完成原稿は別のファイルなので、完成原稿を作っても第一稿は残ります。

---

## 第一稿を書いてもらうとき

Claude Code に次のように伝えてください。

```
本編 第3話の第一稿を書いてください。
プロット：
（ここにプロット）
```

スピンオフなら「スピンオフ so01 の第1話」のように指定します。
Claude は関連資料を確認し、不明点があれば質問してから書きます。
書き終わると **PR（変更の提案）** を作って URL を知らせます。

### PR を確認してマージする

1. 届いた URL を開く。
2. 「Files changed」タブで内容を確認。
3. 問題なければ緑の **「Merge pull request」→「Confirm merge」** を押す。
   これで第一稿が main（正式な保管場所）に保存されます。

直してほしい点があれば、マージせずに Claude に伝えれば修正します。

---

## 完成原稿を登録するとき（ブラウザだけでできます）

1. GitHub でこのリポジトリを開き、`works` → `main` → `final` へ進む。
2. 右上の **「Add file」→「Create new file」**。
3. ファイル名に `ep003_final.md` のように入力。
4. 本文を貼り付ける（1行目は `# 第3話 タイトル`）。
5. **「Commit changes...」** を押し、「Commit directly to the main branch」のまま確定。

すでにある完成原稿を直すときは、ファイルを開いて右上の鉛筆アイコンで編集し、同じように確定します。

> 第一稿のファイル（`drafts/`）を開いて「Copy raw file」でコピーし、推敲してから上の手順で登録すると楽です。

---

## 設定資料を増やすとき

- 共通の設定は `settings/`、作品だけの設定は `works/<作品>/settings/` に置きます。
- 書き方は `templates/` を参考に。「確定」と「未確定・検討中」を分けて書きます。
- 自分で作るのが面倒なら「〇〇の設定ファイルを作って。内容は〜」と Claude に頼めます。

---

## 注意

- 完成原稿は Claude が勝手に変更しません。直してほしいときは明確に依頼してください（その場合も PR で提案されます）。
- Claude は PR をマージしません。マージするのはあなたです。
- パスワードや APIキーなどをファイルに書かないでください。
