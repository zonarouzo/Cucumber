# 作業手順（Claude向け詳細）

`CLAUDE.md` の絶対ルールを前提とした詳細手順。

## 1. 第一稿の執筆

1. ユーザーから「作品」「話数」「プロット」を受け取る。
2. 確認する資料（必要なものだけ）：
   - 作品カード `works/<作品>/README.md`（視点・文体・参照設定）
   - 直前の話の完成原稿（無ければ第一稿）。それより前は必要時に `grep` で該当箇所のみ。
   - 文体ガイド（作品カードに指定があればそれ、無ければ `settings/style-guide.md`。どちらも無ければ確認する）
   - プロットに登場する人物・用語の設定ファイル
3. 不明点・矛盾があれば **執筆前に質問** する（まとめて1回で）。
4. プロットを `works/<作品>/plots/epNNN_plot.md` に保存する（ユーザーの文面をそのまま。整形は最小限）。
5. 第一稿を `works/<作品>/drafts/epNNN_draft.md` に書く。
6. ブランチ作成 → commit → push → main向けPR作成 → URLを報告。

### 第一稿の再執筆

- まだマージ前のPRなら、同じブランチで修正してよい。
- mainにマージ済みの第一稿は上書きせず、`epNNN_draft_v2.md` のように別ファイルで出す。

## 2. ファイル命名

- 話数は3桁ゼロ埋め：`ep001`, `ep002`, … `ep120`
- 話と話の間に挿入する場合：`ep012a`, `ep012b`
- 種別は接尾辞で区別：`_plot` / `_draft` / `_final`
- フォルダ名・ファイル名は半角英数字・ハイフン・アンダースコアのみ。

## 3. 原稿ファイルの書式

本文に技術情報（メタデータ、作業メモ、コメント）を入れない。形式は `templates/episode.md` を参照：

```
# 第N話 タイトル

本文…
```

作業メモ・確認事項はPR説明か会話に書く。

## 4. 設定資料の扱い

- `settings/` は全作品共通、`works/<作品>/settings/` はその作品専用。
- 各設定ファイルは「確定」と「未確定・検討中」の節を分ける（`templates/setting.md`）。
- 新しい設定ファイルは必要になった時点で、ユーザーの了承を得てから作る。作ったら `settings/README.md` の一覧に1行追加する。
- 既存設定を変更するときは、PR説明に「変更内容」と「影響する話・作品」を書く。
- 第一稿で新しく作った細部（脇役の名前、店名など）は設定ファイルに登録せず、PR説明に列挙する。登録はユーザーの指示後。

## 5. スピンオフ

- 新しいスピンオフは `works/spinoffs/<ID>/` に作る（ID例：`so01-short-name`）。作品カードは `templates/work-readme.md` を使い、`works/README.md` に1行追加。
- スピンオフ固有の設定・時系列は、そのスピンオフの `settings/` に置く。共通設定に混ぜない。
- 作業中は対象作品のフォルダと、作品カードで指定された共通設定だけを読む。

## 6. Git / PR

1. `git fetch origin main` で最新を確認し、mainから作業ブランチを作る。
   - ブランチ名例：`claude/main-ep003-draft`、`claude/so01-ep001-draft`、`claude/settings-update`
   - セッションで使用ブランチが指定されている場合はそれに従う。
2. 1つのPRには1つの作業だけを入れる（別の話の原稿をまとめて編集しない）。
3. commit前に `git status` と `git diff --stat` で、`final/` に変更が無いことを確認する（修正依頼時を除く）。
4. push後、main向けPRを日本語で作成。`.github/pull_request_template.md` の見出しに沿う。
5. PRはマージしない。URLと変更概要を報告して終了。
