# 共通設定 一覧

全作品（本編・スピンオフ）に共通する設定資料の置き場所です。
ファイルは必要になったときに追加し、この一覧に1行ずつ書き足してください。

## ルール

- 完成原稿に書かれた事実が最優先。設定資料と食い違う場合はClaudeが報告します。
- 各ファイルは「確定」と「未確定・検討中」を分けて書きます（`templates/setting.md`）。
- 作品ごとにしか使わない設定は `works/<作品>/settings/` に置きます。

## 追加する場合のファイル名（目安）

| ファイル | 内容 |
|---|---|
| `overview.md` | 作品世界の概要 |
| `world.md` | 世界観・舞台設定 |
| `characters/<名前>.md` | キャラクター設定（1人1ファイル） |
| `relationships.md` | 人物相関 |
| `timeline.md` | 共通の時系列 |
| `glossary.md` | 用語集 |
| `style-guide.md` | 執筆ルール・文体ガイド |
| `pending.md` | 未確定設定・検討事項のまとめ |
