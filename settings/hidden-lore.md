# 裏設定（読者には明言しない）

作者が決めた確定設定。**本文・後書きなどで読者に明言しない。**
第一稿では、この設定と矛盾しないように書く。ただし、説明したり匂わせを強めたりはしない。

## 確定

### 暦（月）

上から順に1月〜12月。

| 月 | 名前 |
|---|---|
| 1月 | つる草の月 |
| 2月 | こもれびの月 |
| 3月 | 露しずくの月 |
| 4月 | 花吹雪の月 |
| 5月 | 花結びの月 |
| 6月 | 虹かかる月 |
| 7月 | 露まといの月 |
| 8月 | 陽だまりの月 |
| 9月 | そよ風の月 |
| 10月 | 雨音の月 |
| 11月 | 星降る月 |
| 12月 | 夢うつつの月 |

- 6月「虹かかる月」と11月「星降る月」は、「の」が付かない（原稿の表記どおり）。
- 世界に四季のようなものはなく、気候が大きく変わることはない。

### 日付

- どの月も1日〜30日。月によって日数が違うことはない。

### 女神様

- 名前は**ユゥ**。
- **フゥ**という双子の女神の片割れ。
- ユゥは「みんな一緒の世界」が理想だと思っている。
- その理想を実現するために、住人をみんなきゅうりにして、ピクルスでひとつにしている。
- フゥは個を尊重していたため、ユゥとはわかりあえず、別れた。
